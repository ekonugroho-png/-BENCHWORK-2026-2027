## Cara Menampilkan di GitHub

1. Buka repository GitHub **BENCH WORK** pada branch tempat website disimpan (umumnya `main`).
2. Jika `README.md` sudah ada, buka dan klik ikon pensil **Edit this file**, lalu ganti isinya dengan README gabungan ini. Atau unggah file `README.md` untuk mengganti versi lama pada branch yang sama.
3. Pastikan folder `images/` berisi logo ATMI, ketiga foto instruktur, dan 18 foto alat ukur sesuai nama file di atas.
4. Klik **Commit changes**, lalu buka halaman utama repository. GitHub akan menampilkan logo, foto instruktur, dan galeri alat ukur sesuai urutan.

Untuk website GitHub Pages, pastikan juga `index.html` merujuk ke berkas foto yang sama. **README hanya mengatur tampilan halaman repository, bukan foto pada website.** Jika ingin menerbitkan website, buka **Settings → Pages → Build and deployment**, pilih **Deploy from a branch**, lalu branch website dan folder `/(root)`.

### Jika foto belum terlihat

- Folder harus bernama persis `images` (huruf kecil).
- Nama berkas dan ekstensi `.jpg` harus sama persis (huruf besar/kecil berpengaruh).
- Klik gambar pada repository untuk memeriksa apakah file benar-benar tersedia.
- Untuk perubahan di GitHub Pages, coba muat ulang paksa (`Ctrl + F5`).
